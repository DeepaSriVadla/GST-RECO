# GST-RECO – GST Invoice Reconciliation System

GST-RECO is a web-based GST Invoice Reconciliation System developed using React.js. It helps users compare invoice records, match GST-related fields, and identify matched and unmatched transactions through a clean and interactive interface.

## 🚀 Live Demo

https://deepasrivadla.github.io/GST-RECO/

## 📌 GitHub Repository

https://github.com/DeepaSriVadla/GST-RECO

## ✨ Features

- GST invoice data reconciliation
- Compare and match invoice records
- GSTIN-based invoice matching
- Date-based invoice comparison
- Identification of matched and unmatched records
- Interactive reconciliation results
- Clean and responsive user interface
- Easy navigation between reconciliation sections
- Responsive design for different screen sizes

⚙️ Installation & Setup
1. Clone the repository
git clone https://github.com/DeepaSriVadla/GST-RECO.git
2. Navigate to the project directory
cd GST-RECO
3. Install dependencies
npm install
4. Start the development server
npm run dev

The application will be available at the local development URL provided by Vite.

🏗️ Build for Production
npm run build

The production-ready files will be generated in the dist folder.

🌐 Deployment

GST-RECO is deployed using GitHub Pages with GitHub Actions.

The project is configured to automatically build and deploy when changes are pushed to the main branch.

🎯 Project Objective

The objective of GST-RECO is to simplify the GST invoice reconciliation process by providing an easy-to-use interface for comparing invoice records, matching relevant GST fields, and identifying discrepancies.
